# Symmetries and conformal transformations

Isometries and their generators, Killing vectors, written with the Lie derivative; vectors
that preserve the metric only up to a factor; and how curvature changes when the metric is
rescaled.

## The curvature of a conformally flat surface

**Level 2** · `dg.symmetry.conformal-curvature-2d` · Wald (1984), appendix D

Every surface is locally conformally flat. For \(e^{2\omega}(dx^2 + dy^2)\) the Ricci
scalar is \(-2 e^{-2\omega} (\partial_x^2 + \partial_y^2)\omega\), with \(\omega\) an
unknown function.

```latex
ds^2 = e^{2\omega(x, y)} \left(dx^2 + dy^2\right)
R
```

```python
x, y = symbols("x y")
w = Function("omega")(x, y)
X = [x, y]
g = diag(exp(2 * w), exp(2 * w))
gi = g.inv()
n = 2
Gam = [
    [
        [
            sum(
                gi[a, d] * (diff(g[d, b], X[c]) + diff(g[d, c], X[b]) - diff(g[b, c], X[d]))
                for d in range(n)
            )
            / 2
            for c in range(n)
        ]
        for b in range(n)
    ]
    for a in range(n)
]
ricci = Matrix(
    n,
    n,
    lambda b, d: sum(
        diff(Gam[a][d][b], X[a])
        - diff(Gam[a][a][b], X[d])
        + sum(Gam[a][a][e] * Gam[e][d][b] - Gam[a][d][e] * Gam[e][a][b] for e in range(n))
        for a in range(n)
    ),
)
expected = simplify(sum(gi[b, d] * ricci[b, d] for b in range(n) for d in range(n)))
assert simplify(expected + 2 * exp(-2 * w) * (diff(w, x, 2) + diff(w, y, 2))) == 0
```

## FLRW is conformally flat

**Level 2** · `dg.symmetry.flrw-conformally-flat` · Hawking & Ellis (1973), section 5.3

The Weyl tensor, the part of the curvature a conformal rescaling cannot change, vanishes
for every Robertson–Walker universe.

```latex
g_{\mu\nu} := FLRW(k, a)
C_{\mu\nu\rho\sigma} = 0
```

```python
t, r, theta, phi, k = symbols("t r theta phi k")
a = Function("a")(t)
X = [t, r, theta, phi]
g = diag(-1, a**2 / (1 - k * r**2), a**2 * r**2, a**2 * r**2 * sin(theta) ** 2)
gi = g.inv()
n = 4
Gam = [
    [
        [
            sum(
                gi[A, d] * (diff(g[d, b], X[c]) + diff(g[d, c], X[b]) - diff(g[b, c], X[d]))
                for d in range(n)
            )
            / 2
            for c in range(n)
        ]
        for b in range(n)
    ]
    for A in range(n)
]


def riemann_up(A, b, c, d):  # R^A_{bcd}
    return (
        diff(Gam[A][d][b], X[c])
        - diff(Gam[A][c][b], X[d])
        + sum(Gam[A][c][e] * Gam[e][d][b] - Gam[A][d][e] * Gam[e][c][b] for e in range(n))
    )


down = {
    (A, b, c, d): sum(g[A, e] * riemann_up(e, b, c, d) for e in range(n))
    for A in range(n)
    for b in range(n)
    for c in range(n)
    for d in range(n)
}
ricci = Matrix(n, n, lambda b, d: sum(riemann_up(A, b, A, d) for A in range(n)))
scalar = sum(gi[b, d] * ricci[b, d] for b in range(n) for d in range(n))


def weyl(A, b, c, d):  # in four dimensions
    return (
        down[A, b, c, d]
        - (
            g[A, c] * ricci[d, b]
            - g[A, d] * ricci[c, b]
            - g[b, c] * ricci[d, A]
            + g[b, d] * ricci[c, A]
        )
        / 2
        + scalar * (g[A, c] * g[d, b] - g[A, d] * g[c, b]) / 6
    )


expected = all(
    simplify(weyl(A, b, c, d)) == 0
    for A in range(n)
    for b in range(n)
    for c in range(n)
    for d in range(n)
)
assert expected
```

## A rotation of the sphere

**Level 4** · `dg.symmetry.sphere-killing` · Carroll (2004), section 3.8

The sphere has three rotations; one is generated by
\(\xi = \sin\phi\, \partial_\theta + \cot\theta \cos\phi\, \partial_\phi\). It is a Killing
vector: the metric's Lie derivative along it vanishes.

```latex
ds^2 = d\theta^2 + \sin^2\theta\, d\phi^2
\xi^\mu := [\sin\phi, \cot\theta \cos\phi]
\pounds_\xi g_{\mu\nu} = 0
```

```python
theta, phi = symbols("theta phi")
X = [theta, phi]
g = diag(1, sin(theta) ** 2)
xi = [sin(phi), cot(theta) * cos(phi)]
# (L_xi g)_{mn} = xi^l d_l g_{mn} + g_{ln} d_m xi^l + g_{ml} d_n xi^l
lie = Matrix(
    2,
    2,
    lambda m, v: sum(
        xi[l] * diff(g[m, v], X[l]) + g[l, v] * diff(xi[l], X[m]) + g[m, l] * diff(xi[l], X[v])
        for l in range(2)
    ),
)
expected = simplify(lie) == zeros(2, 2)
assert expected
```

## A dilation of Minkowski space

**Level 4** · `dg.symmetry.conformal-killing` · Carroll (2004), appendix G

The dilation \(\xi = x^\mu \partial_\mu\) is not an isometry but a conformal Killing
vector: \(\nabla_\mu \xi_\nu + \nabla_\nu \xi_\mu = \frac{2}{n} (\nabla_\lambda
\xi^\lambda) g_{\mu\nu}\), in \(n = 4\) dimensions.

```latex
ds^2 = -dt^2 + dx^2 + dy^2 + dz^2
\xi^\mu := [t, x, y, z]
\nabla_\mu \xi_\nu + \nabla_\nu \xi_\mu = \frac{1}{2} (\nabla_\lambda \xi^\lambda) g_{\mu\nu}
```

```python
t, x, y, z = symbols("t x y z")
X = [t, x, y, z]
eta = diag(-1, 1, 1, 1)
xi_up = Matrix(X)
xi_down = eta * xi_up
left = Matrix(4, 4, lambda m, v: diff(xi_down[v], X[m]) + diff(xi_down[m], X[v]))
divergence = sum(diff(xi_up[m], X[m]) for m in range(4))
expected = left == divergence * eta / 2
assert expected and left != zeros(4, 4)  # conformal, but not an isometry
```
