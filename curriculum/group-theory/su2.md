# SU(2) and its representations

The group of unitary 2×2 matrices of determinant one, generated by
\(T_a = \sigma_a / 2\), and its representations of spin \(j = 0, \frac12, 1, \ldots\): the
structure constants and the Casimir operator, characters, which depend only on the angle
\(\theta\) of a rotation and are orthonormal under the Haar measure, the Clebsch–Gordan
series of a tensor product, the two-to-one map onto SO(3), and an integral over the whole
group.

## The Casimir operator of spin one-half

**Level 2** · `group.su2.casimir` · Sakurai (2017), section 3.5

A family of matrices defined at once, \(T_a = \sigma_a / 2\), and the Casimir operator
\(T_1^2 + T_2^2 + T_3^2 = j(j+1) = \frac34\) times the identity, for \(j = \frac12\).

```latex
\sigma_1 := \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}
\sigma_2 := \begin{pmatrix} 0 & -i \\ i & 0 \end{pmatrix}
\sigma_3 := \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}
T_a := \frac{\sigma_a}{2}
T_1^2 + T_2^2 + T_3^2
```

```python
sigma = [Matrix([[0, 1], [1, 0]]), Matrix([[0, -I], [I, 0]]), Matrix([[1, 0], [0, -1]])]
T = [s / 2 for s in sigma]
expected = sum((t**2 for t in T), zeros(2, 2))
j = max(T[2].eigenvals())  # the highest weight, 1/2
assert expected == j * (j + 1) * eye(2) == Rational(3, 4) * eye(2)
```

## The character of spin three-halves

**Level 2** · `group.su2.character` · standard

The character of the spin-\(\frac32\) representation, the trace of \(e^{i\theta J_3}\) over
the states \(m = -\frac32, \ldots, \frac32\): a sum whose index runs over half-integers, in
steps of one. Weyl's formula gives it as \(\sin 2\theta / \sin\frac{\theta}{2}\).

```latex
\sum_{m=-3/2}^{3/2} e^{i m \theta}
```

```python
theta = symbols("theta", real=True)
J_3 = diag(Rational(3, 2), Rational(1, 2), Rational(-1, 2), Rational(-3, 2))
expected = 2 * cos(3 * theta / 2) + 2 * cos(theta / 2)
assert simplify(((I * theta * J_3).exp().trace() - expected).rewrite(exp)) == 0
weyl = sin(2 * theta) / sin(theta / 2)
assert all(abs(N((expected - weyl).subs(theta, t))) < 1e-12 for t in (0.3, 1.7, 4.1))
```

## The Clebsch–Gordan series

**Level 3** · `group.su2.clebsch-gordan` · standard

The character of spin \(j\) as a sum over its weights, then the product of two characters
as a sum of characters: \(1 \otimes \frac12 = \frac32 \oplus \frac12\), the coupling of an
orbital angular momentum one to a spin one-half.

```latex
\chi_j(\theta) := \sum_{m=-j}^{j} e^{i m \theta}
\chi_1(\theta) \, \chi_{1/2}(\theta) = \chi_{3/2}(\theta) + \chi_{1/2}(\theta)
```

```python
theta = symbols("theta", real=True)


def chi(j):  # the weights m = -j, -j + 1, ..., j
    return sum(exp(I * (-j + k) * theta) for k in range(int(2 * j) + 1))


half = Rational(1, 2)
assert expand(chi(1) * chi(half) - chi(3 * half) - chi(half)) == 0
assert chi(1).subs(theta, 0) * chi(half).subs(theta, 0) == 3 * 2 == 4 + 2  # dimensions
weyl = lambda j, t: np.sin((j + 0.5) * t) / np.sin(t / 2)
for t in (0.4, 2.2, 5.0):
    assert abs(weyl(1, t) * weyl(0.5, t) - weyl(1.5, t) - weyl(0.5, t)) < 1e-12
expected = True
```

## An irreducible character has norm one

**Level 3** · `group.su2.orthonormality` · standard

Weyl's formula for the character of spin \(j\), then its norm under the Haar measure of
SU(2) on the angle of rotation, \(\frac{1}{\pi}\sin^2\frac{\theta}{2}\,d\theta\) on
\([0, 2\pi]\): an irreducible character has norm one.

```latex
\chi_j(\theta) := \frac{\sin\left(\left(j + \frac{1}{2}\right)\theta\right)}{\sin\frac{\theta}{2}}
\frac{1}{\pi} \int_0^{2\pi} \chi_1(\theta)^2 \sin^2\frac{\theta}{2} \, d\theta
```

```python
from scipy.integrate import quad

theta = symbols("theta", real=True)
chi_1 = sin(3 * theta / 2) / sin(theta / 2)
assert simplify(chi_1 - (1 + 2 * cos(theta))) == 0  # spin one: m = -1, 0, 1
expected = integrate(chi_1**2 * sin(theta / 2) ** 2, (theta, 0, 2 * pi)) / pi
assert expected == 1
assert integrate(sin(theta / 2) ** 2, (theta, 0, 2 * pi)) / pi == 1  # the measure is normalised
norm = quad(lambda t: (1 + 2 * np.cos(t)) ** 2 * np.sin(t / 2) ** 2 / np.pi, 0, 2 * np.pi)[0]
assert abs(norm - 1) < 1e-10
```

## The structure constants

**Level 4** · `group.su2.structure-constants` · Georgi (1999), chapter 2

The structure constants from the generators by a trace, in index notation:
\(\operatorname{tr}(T_a T_b) = \frac12 \delta_{ab}\), so
\(f_{abc} = -2i \operatorname{tr}([T_a, T_b] T_c)\), and they are the Levi-Civita symbol,
\([T_a, T_b] = i \epsilon_{abc} T_c\). The index of \(T_a\) counts the generators, and its
range is declared as a set, which cannot be read as giving \(a\), \(b\) and \(c\) values.

```latex
a, b, c \in \{1, 2, 3\}
\sigma_1 := \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}
\sigma_2 := \begin{pmatrix} 0 & -i \\ i & 0 \end{pmatrix}
\sigma_3 := \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}
T_a := \frac{\sigma_a}{2}
f_{abc} := -2i \operatorname{tr}\left([T_a, T_b] T_c\right)
f_{abc} = \epsilon_{abc}
```

```python
from itertools import product

sigma = [Matrix([[0, 1], [1, 0]]), Matrix([[0, -I], [I, 0]]), Matrix([[1, 0], [0, -1]])]
T = [s / 2 for s in sigma]
assert all(
    (T[a] * T[b]).trace() == Rational(1, 2) * KroneckerDelta(a, b)
    for a in range(3)
    for b in range(3)
)
for a, b, c in product(range(3), repeat=3):
    assert -2 * I * ((T[a] * T[b] - T[b] * T[a]) * T[c]).trace() == LeviCivita(a, b, c)
for a, b in product(range(3), repeat=2):  # and the commutators themselves
    commutator = T[a] * T[b] - T[b] * T[a]
    assert commutator == sum((I * LeviCivita(a, b, c) * T[c] for c in range(3)), zeros(2, 2))
expected = True
```

## From SU(2) onto SO(3)

**Level 4** · `group.su2.double-cover` · standard

The homomorphism of SU(2) onto SO(3) in index notation,
\(R_{ab}(U) = \frac12 \operatorname{tr}(\sigma_a U \sigma_b U^\dagger)\), with the
exponential of a matrix and its Hermitian conjugate: for a real angle \(\theta\),
\(U = e^{-i\theta\sigma_3/2}\) gives the rotation through \(\theta\) about the \(z\)-axis.
\(-U\) gives the same rotation: the map is two to one.

```latex
\theta \in \mathbb{R}
a, b = 1, 2, 3
\sigma_1 := \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}
\sigma_2 := \begin{pmatrix} 0 & -i \\ i & 0 \end{pmatrix}
\sigma_3 := \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}
U := e^{-i\theta\sigma_3/2}
R_{ab} := \frac{1}{2} \operatorname{tr}\left(\sigma_a U \sigma_b U^\dagger\right)
R_{ab}
```

```python
theta = symbols("theta", real=True)
sigma = [Matrix([[0, 1], [1, 0]]), Matrix([[0, -I], [I, 0]]), Matrix([[1, 0], [0, -1]])]
U = (-I * theta * sigma[2] / 2).exp()
assert U == diag(exp(-I * theta / 2), exp(I * theta / 2))


def rotation(V):
    return Matrix(3, 3, lambda a, b: (sigma[a] * V * sigma[b] * V.H).trace() / 2)


expected = Matrix([[cos(theta), -sin(theta), 0], [sin(theta), cos(theta), 0], [0, 0, 1]])
found = rotation(U).applyfunc(lambda entry: simplify(entry.rewrite(cos)))
assert found == expected
assert simplify(rotation(-U) - rotation(U)) == zeros(3, 3)  # U and -U, one rotation
assert all(abs(N(found.det().subs(theta, t)) - 1) < 1e-12 for t in (0.4, 2.5))  # in SO(3)
assert U.subs(theta, 2 * pi) == -eye(2)  # a turn through 2 pi is -1 in SU(2)
```

## An integral over the group

**Level 5** · `group.su2.haar-integral` · standard

An integral over a group with its Haar measure \(dU\), normalised to 1, as the program
states first: \(\int |\operatorname{tr} U|^4\, dU\) counts the invariants in the product of
four spins one-half, 2. No design of the language integrates over a group.

```latex
\int_{SU(2)} dU = 1
\int_{SU(2)} \left| \operatorname{tr} U \right|^4 dU
```

```python
theta = symbols("theta", real=True)
# Weyl's integration formula: U has eigenvalues exp(+-i theta/2), so tr U = 2 cos(theta/2),
# and the Haar measure on the angle is sin^2(theta/2) d theta / pi on [0, 2 pi].
expected = integrate((2 * cos(theta / 2)) ** 4 * sin(theta / 2) ** 2, (theta, 0, 2 * pi)) / pi
assert expected == 2
# By Monte Carlo: U = a + i(b, c, d).sigma, uniform on the unit sphere in R^4, has tr U = 2a.
q = np.random.default_rng(0).normal(size=(400000, 4))
a = q[:, 0] / np.linalg.norm(q, axis=1)
assert abs(np.mean((2 * a) ** 4) - 2) < 0.05
# And by counting the invariants of four spins one-half: the states that every component of
# the total spin annihilates, 1/2 x 1/2 x 1/2 x 1/2 = 0 + 0 + 1 + 1 + 1 + 2.
from sympy.physics.quantum import TensorProduct

sigma = [Matrix([[0, 1], [1, 0]]), Matrix([[0, -I], [I, 0]]), Matrix([[1, 0], [0, -1]])]


def on(k, s):  # s / 2 acting on the k-th of four spins
    factors = [s / 2 if i == k else eye(2) for i in range(4)]
    return TensorProduct(*factors)


total = [sum((on(k, s) for k in range(4)), zeros(16, 16)) for s in sigma]
assert 16 - Matrix.vstack(*total).rank() == 2
```
